# Mobilewright QA Automation

Mobile UI test automation project using **Mobilewright**, **JavaScript**, and a real Android device.

This project explores and demonstrates a Playwright-style approach to Android mobile application testing, including UI element inspection, locator identification, user interactions, assertions, and automated test execution.

---

## 🎯 Project Overview

The project focuses on automating mobile application UI test scenarios using Mobilewright.

The main objectives are:

- Automate Android mobile UI test cases
- Learn Mobilewright mobile automation
- Inspect mobile UI elements
- Identify reliable locators
- Automate user interactions
- Validate expected UI behavior
- Execute tests on a real Android device
- Generate test reports
- Explore a Playwright-style workflow for mobile testing
